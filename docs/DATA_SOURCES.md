# Sumber Data
- Nomor darurat: hanya `112` di-seed, tanpa sumber & tanggal verifikasi → tampil "Perlu verifikasi sumber". Admin wajib mengisi `source_url` dan `verified_at` dari sumber resmi.
- Instansi seed awal dapat disesuaikan dengan nama instansi yang digunakan.
- Titik evakuasi & batas kecamatan: BELUM ada data resmi. Isi dari BPBD/pemda dan BPS/BIG, catat sumber dan tanggal akses di sini.
- Peringatan cuaca: hanya input manual (berlabel "input manual admin"). Integrasi feed BMKG belum dibuat/diuji.
- Peta: tile OpenStreetMap (patuhi kebijakan penggunaan tile; gunakan penyedia tile sendiri untuk trafik tinggi).
